Bem-vindo ao repositório oficial do meu portfólio web pessoal! Este projeto foi desenvolvido para centralizar e apresentar a minha evolução profissional, competências técnicas e projetos práticos na área de tecnologia.

## 🚀 Tecnologias Utilizadas
* Estruturação e Layout: HTML5, Tailwind CSS
* Interatividade: JavaScript
* Controlo de Versão: Git e GitHub
* Hospedagem: GitHub Pages

## 📁 Projetos em Destaque no Portfólio
* Portfólio Pessoal: Interface moderna, limpa e totalmente responsiva para exibição de carreira e competências.
* Gerenciador de Estoque: Sistema de banco de dados relacional voltado para o setor de eletroeletrônicos e eletrodomésticos, focado em modelagem SQL, relatórios analíticos, margem de lucro e alertas de ruptura.

💡 *Desenvolvido com foco em boas práticas de design web, clareza de código e resolução de problemas reais de negócio.*
